# ChicMuse Supabase Setup

1. Open your Supabase project.
2. Go to SQL Editor.
3. Open `supabase-setup.sql` from this folder.
4. Copy the full SQL and run it once.
5. Go to Authentication > Users.
6. Add your admin user email and password.
7. Open `admin.html`, sign in with that email/password, then add products.

Public visitors do not need accounts. They can only read products.

The admin can add, edit, delete products and upload images after signing in.
